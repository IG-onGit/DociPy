Features

Everything a docs site needs, generated for you

Write Markdown. DociPy handles the menu, search, versions and page metadata.

Your folders become the menu

Put Markdown files in folders. DociPy maps the directory tree to a collapsible side menu and writes a menu.yaml you can adjust.

One command to render

Run docipy render in any folder of Markdown. You get a single static index.html, opened in your browser right away.

Versions kept for you

docipy version raises the number and saves the previous page in a version folder, with a version switcher in the page.

Search and code copy built in

Visitors can search all pages from the header and copy any code block with one click. Code is highlighted with highlight.js.

Your branding

Set your logo, author image, main and dark colors, slogan and two buttons. Pick a Bootstrap icon for every menu entry.

Ready for search engines

Every site ships with meta tags, Open Graph and Twitter cards, JSON-LD, a canonical URL, sitemap.xml and robots.txt.

How it works

From a folder of Markdown to a finished site

Three steps, from install to a published site.

  1. Install the CLI

    Run pip install docipy to get the docipy command.

  2. Render your folder

    Open a terminal in a folder of Markdown files and run docipy render. The first run asks for project name, version, author and email.

  3. Adjust and publish

    Edit menu.yaml, swap assets/logo.ico and assets/author.png, set the Documentation URL with docipy reform, then render again.

Usage

Re-run one command after every edit

DociPy reads the folder you run it in, so your documentation lives next to the Markdown it is built from.

  • Install once with pip, on any operating system.
  • Run it in any folder that contains .md files.
  • Raise the version number when you release new documentation.
See all commands 
# install once
pip install docipy

# render the docs for the current folder
cd my-docs
docipy render

# release a new version of the docs
docipy version

FAQ

Questions newcomers ask

Is DociPy free to use?

Yes. DociPy is open source under the MIT License, so you can use, modify and distribute it. The full license text is in the documentation.

What do I need to write my documentation?

Only Markdown files organised in folders. DociPy builds the side menu from the directory tree and supports fenced code blocks. You can adjust the generated menu.yaml afterwards.

Do I need a server to host the result?

No. The output is static HTML (an index.html plus an assets folder), so you can open it locally or upload it to any host that serves static files. Before publishing, set the Documentation URL with docipy reform. Use a single dot for local versions.

Can I make the site look like my project?

Yes. Replace assets/logo.ico and assets/author.png, choose the main and dark colors, set the slogan and the two main buttons, and pick a Bootstrap icon for each menu entry.
